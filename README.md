# Fiszki do nauki roślin

Strona statyczna (HTML + JS), bez żadnych zależności. Zdjęcia i nazwy pochodzą wyłącznie z czterech PDF-ów z zajęć.

## Publikacja na GitHub Pages
1. Utwórz nowe repozytorium na GitHubie i wgraj do niego całą zawartość tego folderu (`index.html`, `cards.js`, `img1/` i `img2/`).
2. Settings → Pages → Source: „Deploy from a branch”, branch `main`, folder `/ (root)`.
3. Po chwili strona będzie pod adresem `https://TWOJA-NAZWA.github.io/NAZWA-REPO/`.

## Obsługa
Kliknij kartę lub spację, żeby ją odwrócić; strzałki ← → przełączają fiszki. Przyciski 🔊 odczytują nazwę polską i łacińską (syntezator mowy przeglądarki).
